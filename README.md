# 🏦 Sistema Bancário em Java

> Aplicação desenvolvida para simular operações bancárias essenciais, focando em conceitos de Programação Orientada a Objetos (POO) e boas práticas em Java.

## 📌 Sobre o Projeto
Este projeto foi criado como parte dos meus estudos em Ciência da Computação para praticar a construção de sistemas orientados a objetos. 
O programa simula o funcionamento básico de um sistema bancário, permitindo gerenciar contas e realizar transações.

## ⚙️ Funcionalidades
- [x] Criação e gerenciamento de contas
- [x] Depósitos e saques com verificação de saldo
- [x] Transferências entre contas
- [x] Consulta de extrato / saldo

## 🛠️ Tecnologias Utilizadas
- **Linguagem:** Java (JDK 11+)
- **IDE:** VS Code
